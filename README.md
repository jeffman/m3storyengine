# MOTHER 3 Story Engine

In MOTHER 3 there is a collection of bytecode scripts that run on a custom virtual machine.
These scripts control the game's story logic: setting flags, prompting dialogue and animations,
triggering battles and cutscenes, and so on.

This repository contains the following:

* Documentation about the engine itself
* A decompiler that converts script bytecode back to a high-level language (coming soon!)
